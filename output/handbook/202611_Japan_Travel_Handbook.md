## 2. 11月秋季行前打包清單

# 11 月日本秋季旅遊打包必備清單

## 1. 重要證件與隨身貴重物品 (隨身包包，勿託運)
- [ ] **護照正本**（有效期限需在 6 個月以上）
- [ ] **Visit Japan Web (VJW)** 填寫完成與入境 QR Code 截圖
- [ ] **信用卡**（至少 2-3 張不同發卡組織：Mastercard / JCB / Visa，並開通海外交易）
- [ ] **日圓現金**（約每人準備 ¥20,000 - ¥30,000 應付部分僅收現金的老店與神社寺廟）
- [ ] **海外旅遊平安險與不便險保單**（拍照或電子存檔）
- [ ] **機票與住宿預訂確認單**（電子檔/列印本）

---

## 2. 3C 電子與通訊
- [ ] **智慧型手機**（確認安裝好 Google Maps、乘換案內、PayPay / Apple Pay）
- [ ] **日本上網 eSIM 安裝** 或 實體 SIM 卡 / Wi-Fi 機
- [ ] **行動電源**（需符合航空法規，必須隨身攜帶，不可託運）
- [ ] **充電線與快充頭**（日本電壓 100V，插頭為雙平腳，台灣電器插頭可直插無須轉接頭）
- [ ] **相機 / 記憶卡 / 備用電池**

---

## 3. 11 月穿搭衣物 (早晚防寒、室內防熱)
- [ ] **防風大衣 / 輕量羽絨外套**（早晚與夜楓特別拜觀必備）
- [ ] **輕薄發熱衣**（2-3 件）
- [ ] **易穿脫保暖衛衣 / 針織衫**
- [ ] **好穿脫且耐走的健走休閒鞋**（日本自由行日均 15,000-25,000 步，寺廟參拜常需脫鞋）
- [ ] **保暖圍巾 / 輕便手套**（夜間登高或露天展望台適用）
- [ ] **替換內衣褲與襪子**（厚襪佳）
