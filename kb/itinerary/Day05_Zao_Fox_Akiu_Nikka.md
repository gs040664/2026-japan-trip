# Day 05: 宮城藏王狐狸村 ➔ 牧場 1kg 冰淇淋 ➔ 秋保名湯日歸溫泉 ➔ 磊磊峽 ➔ Nikka 宮城峽蒸餾所

---

## 🚇 當日全大眾交通指南
1. **仙台 ➔ 白石站**：JR 仙台站搭乘 **JR 東北本線** 至「白石站」（車程約 48 分鐘，單程 ¥770，刷 Suica）。
2. **白石站 ➔ 藏王狐狸村**：站前轉乘白石市民巴士福岡線（¥200）或共乘計程車（約 20-25 分鐘，每人約 ¥800）直達狐狸村門口。
3. **白石 ➔ 仙台 ➔ 秋保溫泉**：搭車返回白石站搭 JR 回仙台，於仙台站西口 8 號月台搭乘「宮城交通巴士」直達秋保溫泉（50 分鐘，¥860，可刷 IC 卡）。
4. **仙台 ➔ 作並站 ➔ Nikka 宮城峽蒸餾所**：於仙台站搭乘 **JR 仙山線** 至「作並站」（40 分鐘，¥510，刷 Suica），站前搭乘 Nikka 蒸餾所免費接駁巴士（5 分鐘）直達大門口。
